# v1.0 本地发布就绪手册

本手册只准备本地发布产物。它不推送远端、不创建 Git 标签、不创建 GitHub Release，也不录制视频。

## 最终验证

在仓库根目录用实际可用的 Python 环境运行：

```powershell
python -m pytest tests/v10
python -m pytest

Push-Location frontend
npm.cmd test
npm.cmd run build
Pop-Location

docker compose config
python -m industrialops.release.run `
  --project-root . `
  --manifest config\release_manifest_v1.json `
  --output-directory dist
```

确认 `dist/IndustrialOps-Copilot-v1.0.0.zip`、其 `.sha256` 文件和构建报告存在；按 [人工抽查清单](../evaluation/v1.0-manual-checklist.md)记录最终复核。ZIP 由 Git 跟踪文件构建，不能代替私有资料、模型和冻结包的本机准备步骤。

## 由项目负责人执行的外部发布

只有工作树干净、最终测试通过、人工抽查通过且已人工检查 ZIP 后，才执行：

```powershell
git status --short
git push origin main
git tag -a v1.0.0 -m "IndustrialOps Copilot v1.0.0"
git push origin v1.0.0
```

随后在 GitHub Release 页面创建 `v1.0.0`，附上 ZIP 和 `.sha256` 文件，并将发布说明复制自仓库根目录的 `RELEASE_NOTES_v1.0.0.md`。在这些外部操作完成前，项目只能称为“本地发布就绪”。

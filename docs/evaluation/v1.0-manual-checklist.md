# v1.0 人工抽查清单

本清单复核 v0.8 的脱敏验收事实，不取代最终自动化回归。执行时使用独立 RC 资源，不操作默认 `industrialops` Compose 项目，不改动冻结包、模型或评测输入。

- [ ] CNC：`VF-2 报警 552` 返回对应的 CNC 知识包引用；
- [ ] 真空泵：`nXDS10i maintenance schedule` 返回对应真空泵知识包引用；
- [ ] 隔离：上述两次结果不混入另一设备包的引用；
- [ ] 安全：请求绕过联锁或跳过安全前置条件时被确定性门控阻断；
- [ ] 审批：普通用户无法批准工单，`approver`/`admin` 才可做出唯一决定，重启后状态保留；
- [ ] 材料：README、架构、数据边界、第三方声明、评测摘要和发布说明互相链接且不声称视频已录制；
- [ ] 打包：ZIP 可解压，SHA-256 一致，且不含私有资料、模型、索引、数据库、`.env`、凭据或本机报告。

每项应记录通过、失败或未执行。出现失败或未执行时，v1.0 不能标记为 `v1.0_release_ready`。

# v1.0 数据、版权与模型边界

## 公开发布内容

本仓库和 v1.0 ZIP 可公开包含应用代码、自动化测试、公开配置、公开文档、来源治理元数据、评测脚本和小型测试夹具。它们不包含用于本机验收的私有输入。

## 本地受限输入

以下内容的发布级别为 `local_evidence_only`，不得提交 Git、放入 Docker 镜像或重新分发：

- 厂商原始手册、网页快照和受版权保护的页面正文；
- 从上述资料生成的派生语料、结构化候选和冻结知识包；
- BGE-M3、reranker 等本地模型权重；
- 本地数据库、索引、备份、`.env`、密钥、Token、完整日志、浏览器截图和原始验收报告。

公开材料只声明 `cnc_pack_v1.0.0` 和 `dry_vacuum_pump_pack_v1.0.0` 的身份、版本和适用范围，不公开其正文或本机路径。

## 数据身份

- 设备台账、告警历史和工单是合成演示数据；
- 厂商资料是来源事实，不等于项目原创内容；
- 项目译文或派生文本只作为本地处理产物，不作为公开资料再分发；
- 模型生成的候选原因不写入知识包冒充厂商事实；
- 离线回答和 Judge 评测结果必须按各自运行条件解释，不能混作现场设备效果。

## 公开前复核

发布工具只从 Git 跟踪文件建立 ZIP，并拒绝受限路径与真实数据库连接串。发布前仍应人工检查 ZIP 内容、SHA-256、[第三方声明](../../THIRD_PARTY_NOTICES.md)和本文件。

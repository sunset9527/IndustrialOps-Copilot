# 阶段 0：检索、安全与跨设备隔离评测设计

**日期：** 2026-11-08  
**状态：** 待用户审阅  
**范围：** 构建与知识库语料分离的评测题和确定性校验器；不实现模型问答或伪造回答指标。

## 1. 双轨评测集

评测集由两个独立 JSONL 文件构成：

- `scenario_eval_v1.jsonl`：人工改写的自然语言运维场景题。题干不复制索引语料原句，只记录预期设备包、允许来源 ID、允许页码和可验证理由。用于检索结果和引用结果的离线验收。
- `guardrail_eval_v1.jsonl`：规则型边界题。题干不要求回答具体技术结论，而是要求系统拒绝、升级或声明范围不足。覆盖范围外选件、跨设备包、nXDS C/R 变体、危险动作缺少安全前置条件、证据不足五类。

题目只可由本次已归档来源的主题和审核结论派生；题干、预期结果和理由均不得复制正式双语语料中的完整正文片段。

## 2. 题目字段与隔离

每条题目至少包含：

```json
{
  "eval_id": "stable id",
  "eval_type": "scenario|guardrail",
  "prompt": "独立改写的问题",
  "expected_pack_id": "cnc_pack_v1.0.0",
  "expected_outcome": "retrieve|refuse|escalate|insufficient_evidence",
  "allowed_source_ids": ["…"],
  "allowed_pages": [12],
  "rationale": "可审计的验收理由"
}
```

规则题可额外使用 `blocked_markers`，标明触发范围隔离或安全拦截的词。题目不得携带原始手册全文、向量、答案段落或入库记录正文。

## 3. 确定性校验器

校验器接受评测集和检索/回答系统的结构化结果，而非调用模型。它检查：

1. 场景题检索来源与页码是否落在允许证据集合；
2. CNC 与干式真空泵设备包是否被严格隔离；
3. 规则题是否得到指定的 `refuse`、`escalate` 或 `insufficient_evidence` 结果；
4. 安全规则题的回答结果是否包含升级/前置条件标记；
5. 评测题干与正式语料文本是否不完全相同。

输出只报告可重现的通过/失败数和逐题失败理由。没有实际检索或回答结果时，不计算 Hit@k、准确率或“模型能力”数字。

## 4. 初始覆盖

首版至少包括：

- 每个设备包各 3 条场景题，覆盖报警/症状、维护/部件和安全主题；
- 5 条规则题，分别覆盖 SMTC/TSC 等范围外 CNC 选件、C/R 泵变体、跨设备提问、危险维护缺前置条件和已标记不可检索的歧义请求；
- 题目数量、类型、设备包、期望结果和来源 ID 的清单。

## 5. 验收与非目标

评测集文件写入 `data/evaluation/`，与知识库数据隔离且不提交原始资料。生成器在写入前拒绝空字段、未知包、重复 ID、无允许证据的场景题和缺少阻断标记的规则题。

本切片不输出伪造的回答正确率、检索命中率或安全通过率；这些指标只能在后续实际检索/回答实现产生结构化结果后计算。

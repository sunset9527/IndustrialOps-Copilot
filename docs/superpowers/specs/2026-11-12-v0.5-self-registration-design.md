# v0.5：普通用户自助注册设计

**状态：** 已实施并完成真实浏览器注册、登录与设备总览验证（2026-11-18）
**范围：** 为全新本地数据库增加普通用户的自助注册与自动登录；不初始化演示账号，不允许自助获取审批或管理员权限。

## 决策

- 新增 `POST /api/auth/register`，接收用户名、邮箱和密码；
- 复用既有 `create_user()`、密码策略与哈希逻辑；
- 注册账号固定为 `role=user`，请求体没有角色字段；
- 成功后创建不透明 Bearer 会话，返回与登录相同的 token、到期时间和公开用户信息；
- 重复用户名/邮箱或密码策略失败返回脱敏稳定错误；
- 前端 `/register` 提供表单，成功后进入设备总览；
- 审批仍只允许由既有 `approver/admin` 执行，注册用户不能自行审批。

## 验收

1. 注册成功的用户可直接登录并访问设备总览；
2. 注册 API 忽略或拒绝伪造角色，持久化角色始终为 `user`；
3. 重复账号和弱密码被拒绝，不回显密码；
4. 前端展示可恢复的中文字段错误；
5. 现有登录、审批和全量回归不受影响。

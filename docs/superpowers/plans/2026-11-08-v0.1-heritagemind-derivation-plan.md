## 风险与应对

| 风险 | 应对 |
|---|---|
| 母体的单体 API 难以安全迁移 | 只抽取有测试覆盖的通用路由与应用装配，不复制完整 `api.py`。 |
| 通用模块隐藏 craft 依赖 | 每切片先运行残留扫描；发现后提取中性接口或不迁移。 |
| 迁移造成阶段 0 回归 | 每个切片后运行阶段 0 测试；冻结包只读。 |
| 本地模型不可用或自动下载 | 测试使用内存替身；生产配置默认离线保护并报清晰未就绪状态。 |
| 误提交私有资料或脚本敏感信息 | 每次暂存前检查 `.gitignore` 和 `git diff --cached`；脚本单独审查。 |
| 母体后续更新难同步 | 迁移台账固定源提交并按模块记录来源；后续同步以补丁而非重新复制全仓。 |

# v0.6 实施计划：工程化与离线交付

**设计依据：** `docs/superpowers/specs/2026-11-18-v0.6-engineering-offline-delivery-design.md`
**实施方式：** 每个分片遵循红—绿—重构；不修改 `data/packs/`、冻结评测集或未跟踪的下载脚本。

1. 扩展配置模型、预检和离线策略；为离线模型调用阻断先写失败测试。
2. 实现不可变索引身份、原子构建、复用和完整性检查；将诊断运行时改为读取预构建索引。
3. 实现 bootstrap CLI：配置预检、Alembic、演示资产、知识包校验、索引准备与稳定退出码。
4. 实现统一日志脱敏，以及数据库、迁移、知识包、索引、模型和离线策略的只读就绪检查。
5. 用 TDD 调整 API `/ready` 契约；保持 `/health` 仅为存活探针。
6. 构建后端、Vue/Nginx 多阶段镜像与 `db/bootstrap/api/web` Compose 编排；为不含私有资料的构建边界写静态契约测试。
7. 新增 CI，更新 `.env.example`、README、备份/恢复运行手册和阶段记录。
8. 运行全量 Python、前端测试、前端构建、Compose 配置检查和镜像构建；Docker Desktop 启动后由用户执行真实冷启动验收。
